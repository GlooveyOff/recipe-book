# Мои рецепты

Учебное приложение на React для хранения домашней коллекции рецептов. Данные сохраняются в `localStorage`, поэтому после перезагрузки страницы добавленные рецепты не пропадают.

## Возможности

- добавление, редактирование и удаление рецептов;
- проверка обязательных полей формы;
- категории, которые формируются из списка рецептов;
- отдельная вкладка с избранными рецептами;
- поиск по названию с задержкой 400 мс и подсветкой совпадений;
- подсказки при наведении на карточки;
- модальные окна через React Portal.

## Запуск

Требуется Node.js 20.19 или новее.

```bash
npm install
npm run dev
```

После запуска приложение будет доступно по адресу, который Vite выведет в терминале.

## Сборка

```bash
npm run build
```

Готовые файлы появятся в папке `dist`.

## Структура

```text
src/
  components/       компоненты карточек, формы, фильтров и модальных окон
  data/             стартовые рецепты
  App.jsx           состояние и основная логика приложения
  main.jsx          точка входа
  styles.css        стили приложения
```
